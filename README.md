# Hospital Management Project
Made by Juan Cabrera Sanchez on August 2026.
Software Enginnering major at UT Dallas.

This is my final project for my CS 2 course based in Java.
The Hospital Management System utilizes Doctor and Patient objects. 
These objects can be given basic information like name, and ID.
Both objects contain a variable which was not used, however it was a rubric requirement. (Patient: age, Doctor: specialization)

The program utilizes a custom Linked List in order to create the independent Doctor and Patient lists. 
This custom Linked List class has a few public methods for accessability, these methods are Add (allows more
objects to be added to the list), findByID and exists (both go through the list and check for the ID provided), isEmpty, and displayAll.

The program also has an appointment option.
Creating an appointment object requires a patient and a doctor object.
The 'process next appointment' option in the Main file runs the custom queue and deletes the appointment first in the queue while shifting everything forward.
